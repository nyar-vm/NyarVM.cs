模板语法

模板语法

DejaVu 使用 .dora 模板文件，语法基于 <% %> 标签。

变量输出

使用 <% variable %> 输出变量： 

<><% page.title %></h1>

<><% site.description %></p>

支持点号访问嵌套属性： 

<>
<% page.author.name %></span>

条件判断

<% if page.draft %>
  < class="badge">草稿</span>
<% end if %>

if-else 结构： 

<% if page.tags %>
  < class="tags">...</div>
<% else %>
  <>暂无标签</p>
<% end if %>

循环

<% loop posts %>
  <>
    
<><% item.title %></h2>

    
<><% item.summary %></p>

  </>
<% end loop %>

循环中使用 item 引用当前迭代对象。

模板继承

定义基础布局： 

<!-- layouts/default.dora -->
<>

<>

  <% block content %>
  <% end block %>
</>

</>

子模板继承并填充： 

<% extends 'layouts/default.dora' %>
<% block content %>
  <>页面内容</h1>
<% end block %>

模板包含

<% include 'partials/header.dora' %>

模式匹配

<% match page.type %>
  <% if "article" %>
    
<>...</article>

  <% end if %>
  <% if "page" %>
    
< class="page">...</div>

  <% end if %>
<% end match %>

注释

<%# 这是注释，不会输出 %>
