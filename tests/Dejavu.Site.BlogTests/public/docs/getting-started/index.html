快速开始

快速开始

安装

通过 .NET CLI 安装 DejaVu： 

dotnet tool install --global DejavuEngine

或者作为项目依赖引用： 

dotnet add package DejavuEngine

创建第一个站点

  1. 初始化站点目录

dejavu site init my-site
cd my-site

  1. 站点结构 初始化后的目录结构如下：

my-site/
├── config.von          # 站点配置（VON 格式）
├── content/            # 内容目录
│   └── posts/          # 博客文章
├── layouts/            # 模板布局
│   ├── default.dora    # 默认布局
│   ├── index.dora      # 首页布局
│   └── post.dora       # 文章布局
├── static/             # 静态资源
│   ├── css/
│   └── js/
└── data/               # 数据文件

  1. 创建第一篇文章 在 content/posts/ 下创建 Markdown 文件：

---

title: 我的第一篇文章
date: 2026-01-01
tags: [入门, 教程]
---


这是我的第一篇 DejaVu 博客文章！

  1. 构建并预览

dejavu site build
dejavu site serve --port 8080

打开浏览器访问 http://localhost:8080 即可预览。

配置站点

编辑 config.von 自定义站点： 

{
  title: "我的博客",
  description: "一个使用 DejaVu 构建的博客",
  language: "zh-CN",
  navigation: [
    
{"首页": "/"},
    
{"文章": "/posts/"}
  
}
