# sonic dev

开发模式：一键启动编译、代码生成、数据库同步、应用运行和热重载。这是日常开发中使用频率最高的命令——你只需要改 Schema 文件，其余一切自动完成。

## 用法

```bash
sonic dev [选项]
```

## 选项

| 选项 | 短选项 | 说明 | 默认值 |
|:---|:---|:---|:---|
| `--watch` | `-w` | 监听 Schema 文件变化，自动重新编译和同步 | `false` |
| `--config` | | 配置文件路径 | `sonic.config.von` |
| `--env` | `-e` | 目标环境 | `test` |
| `--port` | `-p` | 应用端口 | `8080` |
| `--no-generate` | | 跳过代码生成 | `false` |
| `--no-save` | | 跳过数据库同步 | `false` |

## 说明

`sonic dev` 将开发阶段分散的操作整合为一条命令：

```
sonic dev --watch
      │
      ▼
┌─────────────────────────────┐
│ 1. 编译 Schema              │
│    .her → SchemaIR          │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 2. 代码生成                  │
│    C# 实体 / TS 接口 / SQL  │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 3. 数据库同步（sonic save）  │
│    DDL → test 数据库        │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 4. 启动应用                  │
│    dotnet run               │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 5. [--watch] 监听文件变化   │
│    文件变化 → 增量编译      │
│         → 增量 DDL 应用     │
│         → 热重载代码        │
│    终端输出变更摘要          │
└─────────────────────────────┘
```

## 示例

```bash
sonic dev                   # 启动开发模式（一次性）
sonic dev --watch           # 启动 + 监听文件变化
sonic dev --no-save         # 跳过数据库同步，只生成代码
sonic dev --port 3000       # 指定端口
```

## 与其他命令的关系

| 命令 | 关系 |
|:---|:---|
| `sonic save` | dev 内部自动调用 save（测试数据库同步） |
| `sonic generate` | dev 内部自动调用 generate（代码生成） |
| `sonic status` | 启动前可先 status 查看当前状态 |
